# SISTEM MANAJEMEN KLINIK GIGI
Sistem Manajemen Klinik Gigi adalah aplikasi berbasis Java Console yang dirancang untuk mengelola data operasional klinik gigi secara terstruktur. Aplikasi ini menerapkan prinsip Object-Oriented Programming (OOP) dengan memisahkan komponen data (data model), pengelola logika bisnis (service/manager), dan antarmuka pengguna (entry point).
Program ini memungkinkan pengguna untuk melakukan operasi CRUD (Create, Read, Update, Delete) terhadap data pasien, dokter penanggung jawab, dan catatan rekam medis secara interaktif melalui terminal/console dengan penyimpanan data dinamis berbasis ArrayList.

# 1. Tambah Data Pasien Baru
<img width="341" height="132" alt="Screenshot 2026-09-10 150410" src="https://github.com/user-attachments/assets/13de1ed8-5711-4529-939a-b113b923af6a" /><br>
Fitur ini digunakan untuk menambahkan data pasien baru ke dalam program. Pengguna memasukkan ID pasien, nama pasien, data dokter, ID rekam medis, diagnosa, dan catatan tindakan. Setelah semua data berhasil dimasukkan, program akan menampilkan pesan bahwa data pasien dan rekam medis berhasil ditambahkan.

# 2. Tampilkan Semua Pasien
<img width="426" height="131" alt="Screenshot 2026-09-10 150424" src="https://github.com/user-attachments/assets/b0543c58-a40d-47e9-b063-cdaa0a5735e1" /><br>
Pada menu 2 digunakan untuk menampilkan seluruh data pasien yang telah tersimpan di dalam program. Data yang ditampilkan meliputi ID pasien, nama pasien, dokter, ID rekam medis, diagnosa, dan tindakan. Jika belum terdapat data pasien, program akan memberikan informasi bahwa belum ada pasien yang terdaftar.

# 3. Ubah Data Pasien
<img width="382" height="91" alt="Screenshot 2026-09-10 150533" src="https://github.com/user-attachments/assets/88d32369-b84f-47c9-9112-442b84d05980" /><br>
Menu ke 3 digunakan untuk memperbarui data pasien yang sudah tersimpan. Pengguna memasukkan ID pasien yang ingin diubah, kemudian memasukkan data baru seperti nama pasien, diagnosa, dan catatan tindakan. Seperti gambar pada no 2  diagnosa: gigi berlubang dan tindakan: Segera tambal, kemudian jika terjadi perubahan kondisi pasien maka data yang sudah ada akan diubah menggunakan menu no 3. Setelah proses berhasil, sistem akan menampilkan pesan bahwa data pasien dan rekam medis berhasil diperbarui.
